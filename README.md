# Edzéskövető / Workout Tracker

Progression tracker for group calisthenics training. One self-contained HTML file, no server, works offline.

**Use it:** open `dist/index.html` in a browser (or send the file to someone). Data is stored in that browser
(localStorage); use *Settings → Export* to back it up or move it to another device.

**Develop:** sources are in `src/` (plain HTML/CSS/JS, no dependencies). Run `node build.js` to regenerate `dist/index.html`.

See `PLAN.md` for the design and data model.
